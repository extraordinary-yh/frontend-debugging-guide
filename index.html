YOUR TURN

Practice the diagnosis

“Users say the dashboard became slow after today's release. Some see a slow first load; others see delayed clicks. What do you do?”

Start with your first action, compare your reasoning with the checklist, then propose a testable explanation. Work at your own pace; the timer is optional.

5:00
2. Reveal the checklist and find the first missing measurement
  • Establish impact, affected routes/devices/regions, account size and release timing; separate first load from interaction slowness.
  • Check recent field metrics, consistent percentiles and sample counts, error rates and traces.
  • Use a network waterfall for DNS/connection/TTFB, payload sizes, dependencies and caching; correlate slow requests with server/database spans.
  • Use a performance trace for main-thread long tasks, JavaScript, render/layout/paint and expensive repeated updates. React Profiler applies only to React apps.
  • Reproduce the affected device/network/cache conditions and compare versions under the same conditions.
  • Test one hypothesis and choose a targeted fix; mitigate a severe release regression with a suitable flag or safe rollback.
  • Validate the same metric and cohort plus error and correctness guardrails. Caching is not a universal fix.
